# 28 — Known Limitations and Non-Goals

- No app code or repository has been created by this planning package.
- Exact product/symbol is not selected; runtime discovery must determine eligibility.
- Exact pullback measurement, candle confirmation and exits need approval before order code.
- Exchange endpoint/channel/payload details must be rechecked against current official Delta docs and Demo/Testnet behavior.
- Initial risk percentages are test defaults, not financial advice or a proven safe configuration.
- SQLite is for a single local engine; not multi-user or multi-instance scale.
- The strategy is a hypothesis; no claim of profitability or real-money suitability.
- Historical data availability is not assumed; provenance must be documented.
- Frontend framework and some UI primitives are recommended, not irrevocably locked.
- Deadman/cancel-on-disconnect support is not assumed.
- Mainnet trading, market making, arbitrage, options, multi-exchange routing and autonomous ML-based trading are out of scope for v1.
